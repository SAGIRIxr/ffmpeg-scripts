# ffmpeg-scripts

## 字幕合并到视频.bat

基于 ffmpeg 的 Windows 字幕内嵌小工具。

### 用法

1. 安装 [ffmpeg](https://ffmpeg.org/download.html) 并加入系统 `PATH`。
2. 将「视频文件」和「一条或多条字幕文件」一起选中，拖到脚本图标上。
   - 支持的字幕格式：`srt` / `ass` / `ssa` / `vtt` / `lrc` / `sub`。
   - 拖入几条字幕，软字幕模式就封进几条（各自独立成轨、可切换）。
   - 只拖视频：脚本会提示输入或拖入一条字幕路径。
   - 只拖字幕：脚本会提示输入或拖入视频路径。
   - 直接双击：依次提示输入文件路径。
3. 选择嵌入方式：
   - **硬字幕**：将字幕烧录进画面（重新编码，输出与源同格式）。多条字幕时会让你选择其中一条烧录。烧录 `ass`/`ssa` 时保留字幕自带样式，其余格式使用微软雅黑。
   - **软字幕**：把每条字幕封装为独立可切换轨道（视频/音频 `-c copy` 不重编码，输出 `.mkv`）。`srt`/`vtt`/`lrc`/`sub` 统一转为 srt 轨道；`ass`/`ssa` 原样封装，保留特效样式。
4. 结果输出到视频所在目录。

### 语言识别

软字幕封装时会对**每条字幕**分别自动识别语言并写入轨道语言标记：

- 简体中文 → `Chinese Simplified`
- 繁体中文 → `Chinese Traditional`
- 日语 → `Japanese`、韩语 → `Korean`、英语 → `English`

无法自动识别（或简繁难辨）时，会提示**手动选择**语言，不会留下 `unknown`。

### 编码识别

自动识别字幕文件编码，不会出现乱码：

- UTF-8（含 BOM / 无 BOM）直接使用；
- GBK / GB2312 字幕自动检测并转码（硬字幕走 `charenc`，软字幕走 `-sub_charenc`）；
- 带 BOM 的 UTF-16 交由 ffmpeg 自动处理。

脚本启动时会自动切换到 936 代码页，因此在开启了「Beta: 使用 Unicode UTF-8 提供全球语言支持」（65001 代码页）的系统上界面与输出文件名同样正常。

> 说明：脚本以 GBK 编码保存，请勿用 UTF-8 重新保存，否则中文界面会乱码。
